[사실 자료 — 팀명: 셀아이(CellEye)]
- 팀: 김도윤(대표, 화학공학 박사과정, 전극 코팅 연구 5년), 박서진(CTO, 컴퓨터공학 석사, 비전 AI), 이하람(COO, 산업경영공학, 제조 데이터 분석). 지도교수 자문, 포스텍 창업지원단 시제품 지원 3,000만 원.
- 문제: 전극 코팅 결함(핀홀·두께 편차·이물)은 후공정(조립·화성)에서야 발견되어 셀 폐기·라인 정지로 이어짐. 셀 제조사 C사 품질팀 인터뷰 12건(2026.6~7): 전극 기인 불량률 2~3%, 후공정 발견 시 셀당 손실 약 1.2만 원, 라인당 연 30억 원 규모 손실(C사 담당자 추정). 인용: "코팅 단계에서 잡았으면 버리지 않아도 될 셀이 화성 공정까지 갑니다."(C사 품질팀장)
- 기존 대안과 한계: 라인 후단 2D 비전(표면 결함만, 두께 편차 불가) / 오프라인 샘플 두께계(전수 불가, 샘플 1%) / 육안 검사(60m/min에서 불가능)
- 솔루션: 초분광 카메라+AI로 라인 속도 60m/min 그대로 전수 검사. 두께 편차·핀홀·이물 동시 검출, 결함 좌표를 MES로 자동 전송. 실험실 데이터 4,800장 기준 검출 정확도 96.5%(2D 비전 대비 두께 편차 검출률 0%→94%).
- 트랙션: 포항 전극 소재사 B사 파일럿 라인 무상 실증 진행 중(2026.7~, 3개월). C사 인터뷰 12명 중 7명 "라인당 월 300만 원 이내면 도입 의향". 특허 출원 2건(2026.5). 예비창업패키지 선정(2026), 포스텍 창업경진대회 최우수상.
- 비즈니스 모델: 검사 모듈 하드웨어 라인당 4,000만 원(1회) + SW 구독 라인당 연 1,200만 원. 라인당 3년 누적 7,600만 원.
- 시장: 국내 전극 코팅 라인 약 400개 = 셀 제조사 3사 국내 공장 약 12곳 × 공장당 코팅 라인 약 25개(≈300) + 소재사 라인 약 100개(자체 추정, 출처 없음). 3년 목표 40개 라인 → SOM 약 20.8억 원(40 × 5,200만 원 첫해 기준). 글로벌 배터리 검사장비 시장 규모: [확인 필요].
- 경쟁: 코그넥스·키엔스(범용 2D 비전/두께계, 인라인 두께·핀홀 동시 검출 불가), 국내 검사장비사 D사(오프라인 샘플 검사). 차별점: 인라인 전수 + 두께·핀홀 동시 검출 + MES 연동.
- 시장 진입 전략: 1단계 B사 실증 → 유료 전환(2026.4Q) / 2단계 C사 파일럿 라인 도입(2027.1Q), 레퍼런스 확보 / 3단계 3대 셀사 신규 라인 증설 시 표준 검사 모듈로 제안(2027~).
- Ask: Seed 5억 원(Pre-money 25억 원). 사용 계획: 파일럿 검증 장비 2대 40% / 개발 인력 2명 채용 35% / 인증·특허 10% / 운영 15%. 18개월 마일스톤: 유료 고객 3개 라인 도입, 누적 매출 1.56억 원(HW 1.2억 + SW 연 0.36억), 2028년 상반기 Pre-A. 현재 월 지출 약 800만 원, 잔여 현금 약 5,000만 원(런웨이 6개월).
