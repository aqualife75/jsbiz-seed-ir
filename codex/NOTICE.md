# 배포와 출처 · v1.5.1

v1.5.1은 각 슬라이드의 근거 이미지 조사와 부족한 제품 컷·MVP 화면·설명 시각물의 전문적인 직접 제작을 기본 지침으로 보강한 배포입니다. 생성물의 설계·설명 표기와 실제 사업 증빙의 구분을 유지합니다. 아래 v1.5.0 갤러리 및 기존 교육용 PPTX·PDF·이미지의 바이트와 승인 범위는 그대로 보존하며, 이번 지침 업데이트를 새 예시 덱의 제작·전장 재검수로 표현하지 않습니다.

이 패키지는 정석biz 노하우 IR Deck 작성 원칙을 Codex의 자료 추출·원고 작성·투자자 검수·시각화·발표 검수 절차로 구현한 교육용 도구입니다. 사용자가 지정한 14목차와 최소18장,300초 발표 기준을 따릅니다. 투자 요청·조달 금액·자금 사용계획은 교육 범위에서 제외합니다.

## 공개 예제는 글루코픽입니다

글루코픽은 사용자가 AI로 만든 사업계획서이며 교육 샘플 사용을 명시적으로 승인했습니다. 예제의 회사·고객·인터뷰·검증 수치·제품 설계·팀·시장·가격은 가상 설정 또는 작성 연습을 위한 가정·계획입니다. 실제 사업성과, 의료 효능 또는 투자 준비가 검증되었다는 뜻이 아닙니다. 출처 원안의 의료·시장 수치도 이번 배포에서 최신 원문을 독립 확인한 통계로 제시하지 않습니다.

사용자 승인 범위의 글루코픽 설명과 시각 자산, 이를 재구성한 샘플 덱을 포함합니다. `examples/sample-assets.json`에 자산 출처와 파일 지문을 기록합니다. 원본 전체 교안·참가신청서·실제 팀 분석과 결과·개인 경로는 배포하지 않습니다. 실제 팀 자료는 해당 팀의 프로젝트에서만 사용하며 예제나 배포용 ZIP으로 전용하지 않습니다.

교육생은 사용 권한이 있는 한 팀의 자료를 `자료넣는곳`에 넣습니다. 예제 자료를 실제 사업 근거로 섞거나 가상 고객·매출을 자사 실적으로 사용하지 않습니다. 기존 프로젝트는 설정된 입력 경로를 유지합니다. 내부 원문을 검색 사이트에 업로드하지 않고 공개 조사에 필요한 검색어만 사용합니다.

## 글꼴과 실행 환경

Pretendard는 설치된 글꼴 이름으로 참조하며 폰트 바이너리를 포함하지 않습니다. 사용 가능한 한글 글꼴로 대체하면 그 사실을 기록하고 실제 PPTX를 다시 확인합니다. PDF와 이미지 미리보기는 검토한 글꼴 모양을 유지합니다.

Python 의존성은 `requirements.txt`를 따릅니다. python-pptx는 원본 분석과 이전 형식 호환, Pillow·olefile·PyMuPDF·pypdf는 문서와 이미지 처리에 사용합니다. 각 라이브러리의 라이선스를 따르며 의존성 바이너리는 이 ZIP에 포함하지 않습니다. 복합 장표는 실행 환경의 Node.js와 `@oai/artifact-tool`로 제작합니다. Codex 사용 권한과 도구 사용 가능 여부는 교육생의 환경을 따릅니다.

이 도구는 투자 유치나 모든 논문·통계·이미지의 수집을 보장하지 않습니다. 코드는 구조·참조·계산·파일 변화를 검사하고, 원문이 주장을 지지하는지와 장표가 읽히는지는 에이전트가 검토합니다. 조사하지 않은 검색 로그나 측정하지 않은 발표시간을 만들지 않습니다. 구체적인 배포 검증 결과는 `docs/validation-report.md`를 참고하세요.

## v1.5.0 새 설계 예시와 기존 예시의 구분

2026-09-30 사용자의 제작 과정 재사용 및 GitHub·사이트 배포 요청에 따라, 새로 만든 AI 교육용 제품 설계 이미지 5개와 `examples/visual-design-guide.html`을 추가했습니다. `examples/assets/visual-v2/`에는 제품 콘셉트, 가상의 점심 촬영 상황, 메뉴 확인·기록·회고 화면만 포함됩니다. 각 파일의 생성 출처·권리·캡션·SHA256은 `examples/sample-assets.json`에 기록합니다. 이미지 바이트를 바꾸지 않고 공개 교육용으로 복사했습니다.

이 이미지는 실제 제품 사진·작동 데모·고객 관찰·사용량·정확도·의료 효능을 입증하지 않습니다. 화면의 메뉴·양·시각·요일은 설계 예시이며 구현 상태는 미확인입니다. 실제 팀의 원문·근거·검수 기록·고객 자료·완성 덱을 이 갤러리로 옮기지 않았습니다. 공식 통계나 타사 자료 이미지는 이번 새 자산에 포함하지 않았습니다.

기존 `demo-deck`·`demo-master-deck`의 PPTX/PDF와 `demo-viewer.html`은 상세 20장·발표 18장의 기존 교육용 예시를 그대로 유지합니다. v1.5.0에서 그 38장을 새로 제작하거나 전체 화면·사업 근거를 재검증한 것은 아닙니다. 새 갤러리를 기존 덱의 갱신 완료나 실제 사업 검증으로 표현하지 않습니다. 기존 원안의 의료·시장 수치를 최신 공식 근거로 독립 확인하지 않았다는 제한도 유지합니다.
