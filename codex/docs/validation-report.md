# v1.5.0 시각 제작 절차·배포 검증

검증일: 2026-09-30. 제작 규칙, Codex 공통 코드와 공개 안내의 변경을 검사했습니다. 자동 검사는 사업 사실 확인이나 전문가 시각 검수를 대신하지 않습니다.

## 이번에 확인한 범위

- Codex 전체 unittest: **168개 실행, 167개 통과, 1개 생략, 실패·오류 0**. 생략은 실행 환경에 선택적 PyMuPDF가 없어 수행하지 못한 PDF 추출 검사 1개입니다.
- 실제 PPTX 통합 검사: 임의 팀명·장표 ID, 반복 이미지의 원본 바이트와 native crop, 이미지 중복 제거, 실제 재열기 PNG 생성, 동기화 폴더 밖 임시 빌드, native 차트·표를 확인했습니다.
- 추가 계약 검사: 장표·근거·선택한 이미지 블록 연결, 생성 캡션, 권리·파일 해시, 잘못된 JSON과 경로, 계획 누락·무효 계획의 게시 차단을 확인했습니다. 사업근거가 보완 상태인 유효한 초안 게시도 유지됩니다.
- 기존 교육용 예시를 새 폴더에서 입력 추출→기존 원고·근거 재현→장표별 시각 계획 검증까지 실행했습니다. 기존 예시에 쓰이는 5개 자산만 입력으로 복사하며 별도 갤러리 자산을 원안 판독 자료로 섞지 않습니다.
- 독립 행동 점검: 공장 설비 수리 접수 SaaS, 기획 단계 제품, 인터뷰 메모 3건이라는 다른 업종 사례에서 제품 설계·실제 인터뷰·미확인 시장·실행 계획을 구분하는지 점검했습니다. 해당 사례의 실제 외부 조사나 신규 덱 제작을 수행했다는 의미가 아닙니다.
- 새 AI 제품 설계 갤러리와 안내를 데스크톱·390px 모바일에서 확인했습니다. 5개 제품/상황 자산의 원본과 복사본 해시, 출처·가상 표기·공개 허용 범위를 기록했습니다.
- GitHub의 기존 Claude 안내는 Codex 안내를 별도 병기했습니다. 관련 문서 검사 2개를 직접 실행해 통과했으며, 기존 Claude 코드 전체 pytest는 실행하지 않았습니다.

## 공개 예시와 한계

기존 GlucoPic 상세 20장·발표 18장 PPTX/PDF/전체 뷰어는 기존 파일을 보존했습니다. 이번 릴리스에서 다시 제작하거나 38장을 새로 전장 검수했다고 표현하지 않습니다. 새 [제품 설계 갤러리](../examples/visual-design-guide.html)는 별도의 AI 교육용 시각 자료입니다. 고객·사용 로그·정확도·의료 효능·제품 구현을 입증하지 않습니다.

새 프로젝트는 장표별 계획을 작성하고 대표 구성을 시험 제작한 뒤 두 덱 전체의 실제 화면을 검수하도록 지침을 강화했습니다. 이 절차는 향후 모든 팀의 사업 근거나 디자인 품질을 자동 보장하지 않습니다. 실제 팀의 원본, 내부 분석, 작업 이력, 개인 경로는 공개 배포 대상으로 선택하지 않습니다.

## 글루코픽 결과 검토

[실제 슬라이드 뷰어](../examples/demo-viewer.html)에서 발표본과 상세본을 전환할 수 있습니다. [발표본 PPTX](../examples/demo-deck.pptx)와 [상세본 PPTX](../examples/demo-master-deck.pptx)는 각각 18장·20장입니다. 두 보기 모두 14개 목차를 지키며 문제 정의·기존 대체재·제품 소개·초기 시장 진입 전략은 각각 최소 2장입니다. 투자 요청·자금 사용 내용은 제외했습니다.

Artifact Tool로 생성한 PPTX를 다시 열어 총 38장의 실제 화면을 확인했습니다. 표지의 과한 여백, 세로 제품 화면의 넓은 빈 영역, 퍼널 차트의 순서와 눈금 충돌, 소수점 축 표시, 마지막 일정 단계의 대비를 수정한 화면에서 재검토했습니다. 패키지·글꼴·레이아웃 검사와 네이티브 표·차트 보존 검사를 수행했습니다. 상세본에는 편집 가능한 표 6개·차트 2개, 발표본에는 표 6개·차트 1개가 있습니다.

[발표본 PDF](../examples/demo-deck.pdf)와 [상세본 PDF](../examples/demo-master-deck.pdf)는 실제 최종 렌더를 보존한 열람용입니다. PDF의 모든 페이지에서 포함 이미지의 픽셀이 해당 PPTX 렌더와 일치하는지 확인했습니다. HTML 뷰어도 같은 렌더를 사용합니다.

발표 대본은 공백 제외 1,003자입니다. 장표마다 `글자 수 ÷ 4 + 전환 2초`를 올림해 합산하면 **293초**이며 모든 장표가 각 배정 시간 이내입니다. 전체 배정은 300초입니다. 초당 4자는 분량 계산을 위한 가정이고 실제 발표자의 속도·리허설 측정값이 아닙니다.

## 자료 보호와 배포 검사

배포는 유지 관리하는 파일의 허용 목록으로 만듭니다. 실제 참가팀의 입력·근거·작업 폴더·결과물과 이전 구현 문서는 포함하지 않습니다. 공개 예시의 원고·이미지·PPTX·PDF·HTML은 승인 목록의 SHA256과 일치해야 합니다. 알려진 비공개 식별자와 원본 이미지 지문은 PPTX 내부 노트, UTF-16 XML, PDF, HTML 내장 이미지에서도 검사합니다.

이 검사는 알려진 자료의 혼입과 승인한 예시의 변경을 차단하기 위한 것입니다. 모든 형태의 개인정보를 자동 판별하는 일반 보안 제품은 아닙니다. 실제 팀 자료를 공개 예시 폴더로 복사하지 말고 팀별 프로젝트의 자료 폴더에서 사용하세요.

학생용·개발자용 ZIP은 파일별 SHA256, ZIP CRC, 내부 링크와 필수 실행 파일, 7개 역할을 확인합니다. 자동검사 수와 최종 ZIP별 해시·새 폴더 실행 결과는 배포 ZIP 옆 `정석biz-IR-Deck-v1.4.0-validation.json`에 기록합니다. 새 폴더 검사는 ZIP을 직접 풀고 그 안의 코드로 환경 준비→가상 자료 추출→두 PPTX 생성→검토한 화면과 비교→보완초안 게시까지 확인합니다. 교육생의 새로운 아이템에 대한 AI 조사·사업 판단을 자동으로 검증한 것으로 표현하지 않습니다.

## 초보자 시작과 확인 한계

`정석biz-IR-Deck-v1.4.0.zip`의 압축을 푼 `정석biz-IR-프로젝트`를 Codex에서 열고 `자료넣는곳`에 한 팀의 자료를 넣은 뒤 “우리 팀 IR Deck 만들어줘”라고 요청합니다. 환경 준비와 내부 명령은 Codex가 수행합니다. 사용자 전역 Python을 바꾸지 않습니다.

확인은 Windows와 제공된 Codex 실행 환경 기준입니다. 다른 운영체제, 모든 교육생 PC의 네트워크, 다른 PC의 PowerPoint 화면은 확인하지 않았습니다. 글꼴 파일은 배포하지 않으므로 PPTX의 줄바꿈은 설치된 글꼴에 따라 달라질 수 있습니다. PDF에는 확인한 화면을 보존했습니다.

글루코픽의 고객·제품 성과·가격·팀·전망은 교육용 가정이나 계획입니다. 원안의 외부 통계는 이번 디자인 개편에서 재검증하지 않았습니다. 실제 고객 반응·성능·결제·팀 증빙이 없으므로 사업 최종 검토는 보완 상태로 남깁니다. 인터넷·논문 전체를 전수 검사했다고 주장하지 않습니다.
