# 우리 팀 IR Deck 시작하기

**정석biz 노하우 · v1.5.1**

1. `seed-ir-codex-learner.zip`을 모두 압축 해제하세요.
2. 만들어진 **`정석biz-IR-프로젝트` 폴더를 그대로 Codex에서 여세요.**
3. **`자료넣는곳`**에 한 팀의 자료를 복사한 뒤 요청하세요.

> 우리 팀 IR Deck 만들어줘. 각 슬라이드의 주장과 증거 자료를 뒷받침하는 이미지를 찾아 넣고, 적합한 이미지나 사용권이 없으면 제품 컷·MVP 화면·설명 이미지 또는 편집 가능한 차트·도식을 전문가 수준으로 직접 기획·제작해줘. 생성물은 설명용으로 표시하고 상세본과 발표본의 전체 실제 PPTX 화면을 검수해줘.

사업계획서·발표 자료·표·제품 화면·사진 등 현재 가진 자료로 시작합니다. Codex가 환경을 준비하고 자료를 읽습니다. 첫 준비와 외부 조사에는 인터넷이 필요할 수 있습니다. 오류가 나면 같은 대화에서 “준비 오류를 확인하고 이어서 진행해줘”라고 말하세요.

v1.5.1은 각 슬라이드의 주장과 증거를 뒷받침하는 이미지를 조사해 출처·사용권을 확인하고 실제로 넣습니다. 적합한 이미지나 사용권이 없으면 제품 컷·MVP 화면·설명 이미지 또는 편집 가능한 차트·도식을 전문가 수준으로 직접 기획·제작합니다. 수치·관계는 확인한 자료로 표현하고, 같은 핵심 자산을 여러 장표에서 일관되게 재사용할 수 있습니다.

팀의 원본 제품 사진·화면도 근거와 사용권을 확인해 활용합니다. 원본을 제외하고 새 이미지를 원하면 그 조건을 요청에 덧붙이세요. 생성물은 **설명용·설계안**으로 표시하며 실제 구현·고객·성과의 증거로 쓰지 않습니다. 대표 장표를 먼저 시험 제작하고, **상세본과 발표본의 전체 실제 PPTX 화면을 직접 검수**합니다.

[v1.5.0 AI 제품 설계 갤러리](../examples/visual-design-guide.html)는 보존된 교육용 보조 예시입니다. 제품 콘셉트와 사용 흐름의 표현을 참고할 수 있으며 실제 구현·고객·의료 효능의 증거는 아닙니다.

제작과 검수가 끝나면 **`결과물/결과보기.html`**에서 상세본·발표본·대본·예상 질문·검수 보고서를 확인합니다. 필요한 사업 근거가 부족하면 초안으로 남습니다. 수정은 같은 폴더와 대화에서 이어갑니다.

두 덱 모두 14목차·최소 18장입니다. 문제 정의·기존 대체재·제품 소개·초기 시장 진입은 각각 최소 2장이고, 발표본은 기본 300초입니다. 투자 요청·자금 사용·조달 내용은 제외합니다. 없는 실적을 만들어 채우지 않습니다.

기존 [글루코픽 슬라이드 예시](../examples/demo-viewer.html)는 상세 20장·발표 18장, 총 38장을 그대로 유지합니다. v1.5.0 갤러리와 별도이며, 이번 안내 업데이트에서 기존 PPTX·PDF·viewer를 새로 제작하거나 전장 재검수하지 않았습니다. 글루코픽의 인터뷰·인물·성과·가격·전망은 교육용 가상 사례·가정·계획입니다.
