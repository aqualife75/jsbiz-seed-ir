# 정석biz IR Deck v1.5.0

우리 팀 자료에서 **상세 IR Deck과 5분 발표본**을 만드는 Codex 작업 폴더입니다. 처음이라면 [사용설명서](사용설명서.html)를 여세요.

1. **압축 풀기:** `seed-ir-codex-learner.zip`을 모두 압축 해제합니다.
2. **같은 폴더 열기:** 만들어진 `정석biz-IR-프로젝트` 폴더를 Codex에서 프로젝트로 엽니다.
3. **자료 넣고 말하기:** `자료넣는곳`에 한 팀의 자료를 복사한 뒤 요청합니다.

> 우리 팀 IR Deck 만들어줘. 근거에 맞는 시각자료를 구성하고 상세본과 발표본의 실제 화면을 모두 검수해줘.

준비물은 로그인된 Codex와 우리 팀 자료입니다. 실행 환경은 Codex가 준비합니다. 첫 준비와 외부 조사에는 인터넷이 필요할 수 있습니다. 오류가 나면 같은 대화에서 “준비 오류를 확인하고 이어서 진행해줘”라고 요청하세요.

제작과 검수 후 **`결과물/결과보기.html`**에서 PowerPoint 상세본·발표본, 대본·예상 질문·검수 보고서를 확인합니다. 사업 근거가 부족하면 초안으로 표시합니다. 새 자료나 수정 요청도 같은 폴더와 대화에서 이어갑니다.

## v1.5.0에서 달라진 점

장표의 주장과 읽는 순서를 먼저 정하고, 공식 근거 이미지·직접 제작한 표·차트·도식·AI 설계안을 용도에 맞게 사용합니다. 대표 관계와 구성을 담은 **5~8장 시험 제작**으로 스타일을 점검한 뒤, **양쪽 덱의 전체 실제 PPTX 화면**을 검수합니다. AI 이미지는 실제 고객·제품·성과의 증거로 사용하지 않습니다.

새 [AI 제품 설계 갤러리](examples/visual-design-guide.html)에서 큰 제품 콘셉트 사진과 ‘확인 → 기록 → 되돌아보기’ 화면, 근거에 맞는 시각화 절차를 살펴보세요. **교육용 설계 보조 예시이며 구현·의료 효능은 검증되지 않았습니다.**

기존 [글루코픽 슬라이드 예시](examples/demo-viewer.html)는 **상세 20장·발표 18장, 총 38장**을 그대로 보존했습니다. 기존 [발표본 PPTX](examples/demo-deck.pptx)·[상세본 PPTX](examples/demo-master-deck.pptx)·[발표본 PDF](examples/demo-deck.pdf)·[상세본 PDF](examples/demo-master-deck.pdf)를 이번에 새로 제작하거나 전장 재검수한 것은 아닙니다. 새 갤러리의 이미지가 기존 예시 덱에 반영된 것으로 해석하지 마세요.

정석biz 노하우의 **14목차·최소 18장** 기준을 양쪽 덱에 적용합니다. 문제 정의·기존 대체재·제품 소개·초기 시장 진입은 각각 최소 2장입니다. 발표본은 기본 300초이며 이번 교육 범위에서는 투자 요청·자금 사용·조달 내용을 제외합니다.

글루코픽은 사용자 소유 교육용 가상 사업입니다. 인터뷰·인물·가격·성과·전망은 가상 사례·가정·계획이며 우리 팀 실적으로 바꿔 쓰지 않습니다. 공개 ZIP에는 실제 참가팀 자료나 분석 결과를 넣지 않습니다. [배포와 출처](NOTICE.md) · [시작 안내문](docs/beginner-start.md) · [고급 안내](docs/advanced-guide.html)
