## 표지

### 누구의 어떤 문제를 어떻게 해결하는가

계획: 글루코픽은 직장인 2형 당뇨인의 식전 선택과 기록 누락을 사진·행동 안내·연결 리포트로 돕는다.

근거: 계획: 구내식당·외식이 잦은 35~55세 고객과 식전·식후 두 사용 순간에 집중한다.

추가로 확인할 내용: 팀명·법인명 일치 확인; 제품은 설계 화면이며 작동 상태 확인 필요

## 문제 배경 및 최근 트렌드

### 지금 어떤 시장 변화와 기회가 있는가

국내 당뇨 관리 대상은 크며, 주요 앱은 사진 AI 기록을 이미 제공한다. 식전 사용성의 추가 가치는 별도 검증이 필요하다.

근거: 2021–2022년 국내 30세 이상 전체 당뇨병 추정 인구는 5,333,837명이다. 2형만 또는 유료 이용자 수가 아니다.

파스타와 닥터다이어리의 공식 안내에 사진 AI 기록 기능이 있다. 실제 성능 비교는 하지 않았다.

2021~2022년 전체 당뇨병 유병률은 30대3.3%,40대8.4%,50대16.7%,60대22.7%,70세이상30.6%다. 유료 수요나 2형 직장인의 인구로 전용하지 않는다.

추가로 확인할 내용: 목표 고객군에서 기록 행동이 어떻게 변했는지 보여 주는 시계열·실제 사용자 조사; 2026년 현재 2형·직장인 고객군의 별도 수요 규모

## 문제 정의

### 해결할 필요가 큰 문제인가

가정: 가설: 직장인 고객은 식사 전에 무엇을 조절할지 판단하기 어렵고, 수기기록이 누락되어 패턴을 찾지 못한다.

근거: 계획서는 외식·구내식당의 판단과 식사·혈당 연결을 반복 사용 상황으로 제시한다.

가상 인터뷰로는 문제의 빈도나 강도를 검증할 수 없다.

추가로 확인할 내용: 실제 고객별 문제 빈도·소요시간·누락 횟수와 원본 인터뷰 필요; 가상65명 제외

## 기존 대체재의 문제점

### 고객의 기존 해결 방식은 무엇인가

공식 제품 안내에서 파스타와 닥터다이어리의 사진 AI 기록 기능을 확인했다. 목표 고객이 실제로 어떤 대안을 쓰는지는 별도 조사해야 한다.

근거: 가정: 계획서는 기록·센서 확인·검색을 세 가지 해결 방식으로 제시한다.

파스타는 사진 인식·혈당 리포트·CGM 연동을, 닥터다이어리는 사진 식단 기록·건강 데이터 관리를 안내한다. 직접 앱 성능은 시험하지 않았다.

추가로 확인할 내용: 목표 고객의 실제 대안 사용 비율·선택 이유·전환 비용; 동일 과업에서의 성능·시간·비용 실측 및 잠재 대안 비교

### 대체재가 해결하지 못하는 부분은 무엇인가

가정: 가설: 외식의 양 보정과 식전 실행 안내, 기록 연결에 남은 불편이 기회다.

근거: 현재 계획서의 타사 비교는 자사 목표와 타사 사용 추정의 조건이 다르다.

사진 AI 기록이 이미 제공되므로 사진 입력 자체를 독점 차별점으로 주장할 수 없다. 식전 사용성과 수정 부담의 차이를 검증할 계획이다.

추가로 확인할 내용: 직장인의 식사 전 선택·섭취량 수정·기록 지속에서 남는 불편의 실제 관찰; 동일 조건의 개선량·우월성 실측

### 대안 사이의 차이와 고객이 중요하게 보는 비교 기준은 무엇인가

계획: 같은 식사 과업에서 입력 시간·식전 안내·연결 정확도·총비용을 비교한다.

근거: 자사30초는 목표이고 비교표는 타사와의 과업 조건이 다르다.

추가로 확인할 내용: 공통 메뉴·기기·참여자·가격기준일·평가 절차와 고객 중요도 조사 필요

## 해결방안

### 고객 문제를 대안보다 어떻게 더 잘 해결하는가

계획: 사진으로 식사기록을 줄이고 식전 행동 안내와 식후 데이터를 연결한다.

근거: 계획: 식전 선택 문제는 사진 기반 안내로, 기록 누락은 자동 연결·주간 리포트로 대응한다.

계획: 사진의 판별 한계와 데이터 부족을 알린다.

추가로 확인할 내용: 기존 대안 대비 개선량·조건별 정확도·사용성 측정 없음;30초는 목표

근거: 계획: 세 가지 메뉴의 클릭형 프로토타입에서 완료시간과 다음 사용 의향을 관찰한다.

추가로 확인할 내용: 실제 사용과업 성공률·완료시간·오류·이탈 로그 없음;30초 검증 전
