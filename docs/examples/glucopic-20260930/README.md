# 글루코픽 시각화 개선 예시 · 보완 초안

2026년 9월 30일 제작한 상세본 22장과 5분 발표본 18장의 실제 PPTX 렌더 이미지입니다. 사용자가 지정한 결과물의 공개 요청에 따라 게시했습니다.

[전체 슬라이드 보기](https://accelerating.co.kr/resources/seed-ir-deck/examples/glucopic-20260930/index.html)

## 파일

- `index.html`: 두 덱 40장 전체를 원본 비율로 보여주는 웹 뷰어. ZIP을 풀고 열어도 볼 수 있습니다.
- `master/`, `pitch/`: 기존 시각 검수와 해시가 일치하는 1600×900 원본 PNG.
- `glucopic-master-draft.pptx`, `glucopic-pitch-draft.pptx`: 사용자 지정 PPTX와 바이트가 동일한 편집 가능한 원본.
- `glucopic-master-slides.pdf`, `glucopic-pitch-slides.pdf`: PNG의 픽셀과 비율을 보존한 이미지 기반 PDF. 편집에는 PPTX를 사용하세요.
- `pitch-script.md`, `questions-and-answers.md`: 원본 대본과 예상 질문·답변.
- `manifest.json`: 각 파일·슬라이드 순서와 SHA256.

## 상태와 사용 범위

계획·가정·미확인 표시를 유지한 보완 초안입니다. AI 생성 제품 설계안과 상황 이미지는 실제 구현·고객·효능의 증거가 아닙니다. 제품·고객·가격·시장·팀 등에 확인할 사업 근거가 남아 있습니다. 발표 296.8초는 대본 기준 추정이며 실제 리허설 값이 아닙니다.

기존 시각 검수와 현재 PPTX·40개 PNG 지문의 일치를 확인했습니다. 이번 공개 작업에서 원본 슬라이드나 사업 내용을 새로 수정하지 않았습니다. 표·차트의 원문과 출처, 이미지의 설계·가정 표시는 슬라이드와 발표자 노트에 유지되어 있습니다.

교육·검토 예시로 열람할 수 있습니다. 실제 팀의 실적 자료로 전용하거나 출처·가정 표시를 제거하지 마세요. 외부 자료의 권리는 각 원저작자에게 있으며, 이 공개는 외부 자료에 별도의 재사용 권리를 부여하지 않습니다.
